About THREATNEX.

An AI-assisted intrusion detection project for network security monitoring.

See threats. Understand patterns. Investigate smarter.

THREATNEX is a machine-learning-based intrusion detection dashboard. It displays network classifications, summarizes security events, and exposes model evaluation metrics through a Flask web application.

Operational Engine Disclosures

THREATNEX executes classification inference on 12 connection summary vectors using a scikit-learn RandomForest model trained on NSL-KDD. Changing UI thresholds adjusts alerting sensitivity only; it does NOT alter underlying model weights or invent synthetic detections.

Model ArchitectureRandomForestClassifier (100 Trees)
Model Binary AvailabilityLoaded (model.joblib, ~27.4 MB)
Evaluation BenchmarkNSL-KDD Standardized Test Partition (22,544 vectors)
Evaluation MetricsAccuracy: 99.8% | F1 Score: 99.8% | Precision: 99.8%
Input Features (12)duration, protocol_type, service, flag, src_bytes, dst_bytes, count, srv_count, same_srv_rate, diff_srv_rate, dst_host_count, dst_host_srv_count
Output Attack Classes (5)normal, dos, probe, r2l, u2r
Model File TimestampLoaded & verified
Operating ModeVector summary inference (No raw packet sniffing / No TLS decryption)

Architectural Disclosures & Boundaries
  • Telemetry inference is performed strictly on connection summary feature vectors (e.g. durations, byte volumes, error rates).
  • No raw promiscuous network interface card packet tap or kernel packet capture driver is active.
  • Encrypted application payloads (TLS/HTTPS) are not decrypted or intercepted.
  • No automated external firewall or routing table rule mutations are enacted without operator verification.
